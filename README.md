## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/MrRogueKnight/IITG_Summer_Analytics_2025_Data_Analysis.git
cd IITG_Summer_Analytics_2025_Data_Analysis
```

### 2. Set up your environment
- Recommended: [Anaconda](https://www.anaconda.com/products/distribution) or [Miniconda](https://docs.conda.io/en/latest/miniconda.html)
- Or use `virtualenv` for Python 3.x
- Install required libraries (most notebooks use pandas, numpy, matplotlib, scikit-learn, etc.)

Example (using pip):
```bash
pip install numpy pandas matplotlib scikit-learn jupyter
```

### 3. Launch Jupyter Notebook
```bash
jupyter notebook
```
Open the desired notebook from your browser and start exploring!
